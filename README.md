# 美容院 POS (SalonPos)

美容院用的 PWA 网页应用，纯 HTML / CSS / JavaScript，无需后端。

## 功能

- **预约日历**：月历查看与安排顾客预约，时段重叠提醒，WhatsApp 预约提醒，完成时扣除配套次数
- **配套收款**：记录配套销售与分期付款，追踪每位顾客的剩余次数和尚欠余额，WhatsApp 发送收据
- **顾客管理**：新增、编辑、搜索顾客，查看每位顾客的配套、预约和付款记录
- **设置**：店铺资料、货币、WhatsApp 国家区号、配套模板、数据导出/导入备份

## 本地运行

```bash
python -m http.server 5173
```

然后打开 http://localhost:5173

## 注意

数据保存在浏览器的 localStorage 中，只存在当前设备。请定期在「设置」中导出备份。
手机安装（添加到主屏幕）需要通过 HTTPS 访问，例如部署到 GitHub Pages。
